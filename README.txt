THE R15M RIDER — Explore Odisha demo

Included files: index.html, style.css, script.js.

Features: responsive mobile-friendly design, Odisha destination cards, Google Maps search links, sample travel photos, Instagram profile/contact and YouTube channel. No WhatsApp button is included.

To preview: open index.html in a browser after extracting the ZIP. Sample photos and Google Fonts require internet access.

To publish using GitHub Pages:
1. Extract this ZIP.
2. Upload index.html, style.css and script.js to the root of your GitHub repository.
3. In GitHub, open Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then Save.
5. Open your GitHub Pages URL after deployment finishes.

The images are sample photos, not your personal R15M photos. Replace them with your own photos when you have them. This package is a website demo and has not been published to your GitHub account automatically.
